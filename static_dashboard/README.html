GNEM static dashboard / 静态看板

This is a separate, read-only HTML report. It does not change the employee application or database.

Create from the factory SQL database

.venv\Scripts\python static_dashboard\generate_static_dashboard.py --date 2026-08-18

Create from Excel

Export two sheets named production_records and abnormality_reports, keeping the same column names as the SQL tables. Then run:

.venv\Scripts\python static_dashboard\generate_static_dashboard.py --source excel --excel C:\Reports\daily.xlsx --date 2026-08-18

The generated file is placed in static_dashboard\output. Double-click the HTML file to open it, or send that one file to a manager. It is static: regenerate it whenever you want a new snapshot.

For Excel input, run .venv\Scripts\pip install -r requirements.txt once after the requirements update.
