GNEM Slurry Production Tracker System documentation

HTTPS certificate setup / HTTPS 证书设置

This guide describes the current single-server factory setup. GNEM is internal-only and must not be exposed to the internet.

Correct employee link

Employees and managers use https://slurry-management.local . Do not use http://...:5000: port 5000 is private between Caddy and the local Python application.

How the certificate works

Caddy listens on HTTPS port 443 and creates an internal certificate for slurry-management.local. The factory root certificate file is deployment\caddy\GNEM-Factory-Root-CA.crt. It is a trust file, not a password; distribute it only to approved factory devices.

Set up each approved employee computer

  1. Connect the computer to the factory network.
  2. Make sure slurry-management.local resolves to the factory server. Until IT creates internal DNS, add this line to the computer's hosts file as Administrator: 172.23.19.139 slurry-management.local. Replace the IP only if the server IP changes.
  3. Copy GNEM-Factory-Root-CA.crt from the server's deployment\caddy folder.
  4. Open the certificate file, choose Install Certificate, select Local Machine, then store it in Trusted Root Certification Authorities. Administrator permission is required. IT can deploy it centrally with Group Policy instead.
  5. Close every browser window, open a new browser, and visit https://slurry-management.local. The browser must show a secure lock with no warning.

Server settings that must remain in place

WEB_HOST=127.0.0.1
WEB_PORT=5000
ALLOWED_HOSTS=localhost,127.0.0.1,172.23.19.139,slurry-management.local
BEHIND_TLS_PROXY=true

Caddy configuration: deployment\caddy\Caddyfile.

https://slurry-management.local {
    tls internal
    reverse_proxy 127.0.0.1:5000
}

Firewall and network boundary

  • Allow TCP 443 only for Private/Domain factory networks.
  • Keep TCP 5000 private to the server; do not create a firewall rule for it.
  • Block TCP 3306 from employee devices.
  • Never port-forward 443, 5000, or 3306 to the internet.

Troubleshooting

Symptom Check
Site cannot be reached The factory server must be awake; run Start_GNEM_Slurry_Tracker.cmd. Confirm the hosts/DNS name points to the server and firewall allows 443.
Not secure or certificate warning Do not continue. Install the factory root certificate into the Local Machine trusted-root store, restart the browser, and confirm the URL is exactly https://slurry-management.local.
Port 5000 works but HTTPS does not Do not use port 5000 as a workaround. Check logs\caddy.stderr.log and confirm Caddy is listening on 443.
Only one computer fails Its hosts/DNS entry or trusted root certificate is missing; fix only that computer.

Renewal and change control

Caddy's internal certificate renews automatically while the gateway is running. Do not delete Caddy's data folders, replace the Caddyfile, or generate a new root certificate without IT approval: existing employee devices would no longer trust the replacement. If the factory server IP changes, update internal DNS or every approved hosts file and test HTTPS again.
