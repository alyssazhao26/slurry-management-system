System architecture

Components and trust boundary

Employee browsers -- HTTPS --> Factory server
                               |- Reverse proxy → web application
                               `- MySQL (local only)

Manager computer -- HTTPS --> Factory server
Power BI / future AI -- read-only SQL --> Factory server

Employee devices are not trusted with database credentials. The boundary is the HTTPS web application. The browser submits a record; the app validates and writes it to local MySQL in one transaction.

Data flow

  • Employee submits a production or abnormality form.
  • HTTPS delivers it to the factory server application.
  • The app validates quantities, dates, permitted tracker fields, and form data.
  • The app writes the record to system_import and records an audit event.
  • Rule-based checks create manager-only exceptions when conditions are met.
  • Manager browser view reads manager-only summaries through the web app.
  • Power BI and future AI read through their own read-only MySQL account.

Database ownership

Database/schemaPurpose
slurry_managementApplication model, audit events, exception queue, migrations
system_importReporting source tables: production, abnormalities, form definitions, sync receipts

MySQL data files stay on the factory server local SSD. A shared drive is appropriate for encrypted backups, not the live MySQL data directory.
