Operator and manager user guide

Operator workflow

No operator sign-in is required. Use the factory internal web link provided by management.

Production data

  • Select Log production.
  • Enter date, shift, machine, formula, batch, planned quantity, actual quantity, and qualified quantity.
  • Add notes if needed, then select Save production record.
  • Confirm the success message, then select View saved records if you need to check the entry.

Abnormality data

  • Select Report abnormality.
  • Enter date, shift, machine, event type, severity, downtime, description, and immediate action.
  • Select Save abnormality report.
  • Open Abnormality tracker to update responsible person and expected/actual completion dates for open items.

Operators cannot view rule-based analysis, manager dashboard data, solution details, or close an abnormality.

If saving fails

Do not assume the record saved. The current release does not retain a record offline in the browser. Retry when the server link returns; if the outage continues, follow the approved paper/manual contingency process and enter records once service is restored.

Manager workflow

  • Select Manager workspace.
  • Enter the manager PIN.
  • Review daily metrics and Refresh exception analysis.
  • Use complete tracker information to document resolutions and monitor open work.
  • Configure a new form field only when it has a clear business purpose and reporting impact has been considered.
  • Select Sign out when finished, especially on a shared manager computer.

Managers should use the web manager workspace for operational review. Power BI is appropriate for broader reporting and trends through its read-only account.
